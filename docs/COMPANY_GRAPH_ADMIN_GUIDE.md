# Company Graph administrator guide

Company Graph shows the records and governed relationships the signed-in
administrator is permitted to inspect. Start with the scope and Graph Health
control, then use search or an operational layout to focus the workspace.

Select a node to inspect facts, incoming and outgoing relationships, risks, work,
decisions and permitted actions. Select an edge to inspect source, predicate,
target, evidence, assertion class, state, confidence and history. “Ask Idjwi” uses
that same governed selection. Relationship Review governs proposed links; Graph
Quality creates owned repair work.

Graph Health distinguishes five supporting states:

- ✓ Available — authorized and usable.
- ○ Empty — authorized and working, with no records.
- ⊘ Unauthorized — ask an administrator to review role or scope.
- ! Unavailable — retry or inspect service health.
- △ Degraded — usable in part; follow the displayed operator action.

Use View → Accessible representation for a keyboard record list, relationship
table, hierarchy, or textual summary. Expansion dialogs close with Escape and
return focus to the control that opened them. A partial or truncated graph is not
the complete organization; inspect Graph Health before acting.
